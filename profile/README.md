# Horizon Social Network

A small social network for the Horizon community (students, staff and teachers), built as the M2
integration project: software development, DevOps and SRE.

| Repository | What it holds |
| --- | --- |
| [horizon-backend](https://github.com/Horizon-Social-Network-M2-SRE/horizon-backend) | FastAPI modular backend and Celery worker |
| [horizon-web](https://github.com/Horizon-Social-Network-M2-SRE/horizon-web) | Next.js web app, mobile-first |
| [horizon-infrastructure](https://github.com/Horizon-Social-Network-M2-SRE/horizon-infrastructure) | Reusable CI, Compose, Helm, observability, SLOs |
| [horizon-documentation](https://github.com/Horizon-Social-Network-M2-SRE/horizon-documentation) | Plan, charter, ADRs, decisions, sprint notes |

**Stack:** Python · FastAPI · MongoDB · Redis · Celery · Next.js · TypeScript · Docker ·
Kubernetes (minikube) · Helm · Traefik · Prometheus · Grafana · Sloth
